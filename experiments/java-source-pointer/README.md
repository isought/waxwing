# Extreme check: a source-location hint for a Java JAR

Date: 2026-09-14. Status: four fresh sessions completed.

## Question

Does a one-sentence dependency-source hint change the effort required to explain
two calls through a JAR? This isolates a navigation hint from the earlier
architectural-note experiment. It does not test stale explanations or unsupported
business conclusions.

## Fixture and control

The caller is five lines:

```java
package example;
import vendor.rules.Adjustment;
public class Quote {
    public static int quote(int amount) { return Adjustment.apply(amount) + 3; }
}
```

The dependency is compiled into `lib/vendor-rules.jar`. Its source is six lines:

```java
package vendor.rules;
public class Adjustment {
    public static int apply(int amount) {
        return amount < 100 ? amount + 7 : amount - 11;
    }
}
```

Source is present in **every** checkout at
`vendor-drop/2025-11/source/vendor/rules/Adjustment.java`. The only condition
difference is this sentence appended to AGENTS.md:

> Source for vendor.rules.Adjustment in lib/vendor-rules.jar is in vendor-drop/2025-11/source/.

All subjects get the same `CLAUDE.md` containing `@AGENTS.md` and the same neutral
read-only instruction. The task names `app/src/example/Quote.java`, asks for
`Quote.quote(99)` and `Quote.quote(105)`, requires implementation evidence, and
limits the answer to 200 words. It does not mention the source hint.

The evaluator compiled the JAR and caller, then ran an external probe: **109 and
97**. The probe and its output were not available to subjects. Subjects could
only list, search and read files; they could not run or decompile the JAR.
This is a tiny recursively searchable tree; no discovery difficulty was added.

Descriptive medians: hinted input was **29.6% lower**, elapsed time **29.7% lower**,
and calls **25% lower**, with equally correct answers. Estimated cost was only
4.2% lower; cache accounting changes the relationship between tokens and price.
Total CLI-estimated cost was $0.14956, not a statement of an extra cash charge.

Accounted input sums uncached input, cache creation and cache reads across model
requests. It is not unique content. All four read both implementations and
correctly applied the `<100` boundary and caller's `+3`. Run 01 explicitly cited
AGENTS.md as the source/JAR mapping authority. Detailed records include the CLI's
small auxiliary model usage separately from main-model usage.

### What actually saved a tool call?

Both controls did:

1. Glob for Quote.java.
2. Read Quote.java.
3. Glob for Adjustment.java.
4. Read Adjustment.java.

Both hinted sessions did:

1. Read Quote.java directly.
2. Glob the tree (`**/*` or `**/*.java`).
3. Read Adjustment.java.

The avoided call was a caller-location search, although the caller's exact path
was already in every task prompt. **The hinted sessions still searched for the
dependency source.** Therefore the intended mechanism, directly using the supplied
dependency folder to eliminate that search, was not cleanly demonstrated.

This is a favorable observation for the hint condition, not a statistically
established effect or proof of a particular internal reasoning mechanism. Four
sessions, shared caches, and an extremely small task limit the conclusion.

## Interpretation

The earlier architectural-note result cannot justify saying cached knowledge
never helps. Here the hinted condition produced equally correct answers with
less observed work. However, ordinary search also found the dependency easily,
and the tool-call difference occurred at a different step than intended.

This distinguishes three things: providing a missing location, reducing search
effort, and improving application of complex conditions. They should not be
treated as one universal claim about memory. This test says nothing about whether
a broader summary will preserve tax/payment qualifications under a complex task.

No claim of net preparation savings: the hint was evaluator-authored in one
sentence, not generated by an author model; fixture construction and coordinator
effort are not included in subject token totals.
